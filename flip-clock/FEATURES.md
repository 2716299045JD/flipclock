### 观察

1. **逐位翻页 + 12/24 + 秒开关 + 常亮** 是所有产品的公约数，缺一个就不成立。
2. **纯摆件型（网页/屏保）** 功能极窄，靠"好看"取胜，几乎不做计时。
3. **手机 App 型** 后期全部长成了"番茄钟 + 白噪音 + 自习室"的复合体 —— 这是为了留存和变现硬加的，跟翻页时钟本身无关。
4. **小组件、悬浮窗、学霸模式** 只有原生 App 有，网页端物理上做不到。
5. **主题数量** 从 4 套到 20+ 套都有，但没有任何一款因为主题多而获得口碑。

## 二、取舍决策

判断标准三条：
- **A 是否服务于"看时间"这个核心动作**
- **B 网页端能否低损耗实现**
- **C 不增加日常使用负担**

### 留下（13 项）

| 功能 | 理由 |
|---|---|
| 逐位翻页 + 秒 | 核心，A 满足 |
| 12/24 小时制 | 必备，成本近零 |
| 秒显示开关 | 关秒后每分钟才翻一次，省电，实用 |
| 日期与星期 | 摆件需要日期锚点，成本低 |
| 屏幕常亮 | 摆件不常亮等于废了 |
| 沉浸全屏 | 隐藏全部 UI，只留数字 |
| 横竖屏 + 任意尺寸自适应 | 一套公式覆盖手机/平板/横屏 |
| 主题配色 3–5 套 | 够用，砍掉 20 套的选择瘫痪 |
| 翻页音效开关 | 整机的灵魂之一，A 强相关 |
| 夜间自动调暗 | 床头场景必需 |
| 防烧屏像素偏移 | OLED 常亮必备，实现成本极低 |
| 番茄钟（25+5 可调） | 用户明确要求，且是"点进去有事可做"的落点 |
| 正计时 / 倒计时 | 同上 |

### 附加（3 项）

| 功能 | 理由 |
|---|---|
| 专注记录（今日番茄数 / 今日总时长 / 近 7 日） | "点进去有东西计入"的落点，本地存储即可 |
| 结束时提醒（声音 + 振动 + 通知） | 计时器不提醒等于没有 |
| 桌面快捷方式（长按图标直达番茄钟/倒计时） | 小组件的网页端替代品 |

### 砍掉（8 项）

| 功能 | 砍掉理由 |
|---|---|
| 桌面小组件 | iOS 无 Web Widget；Android 的 Web App Widgets 至今实验性、覆盖率极低。投入产出比不成立 |
| 锁屏 / StandBy / 屏保替代 | iOS 系统级禁止，网页无解 |
| 悬浮窗 | 浏览器无法创建系统级悬浮窗 |
| 学霸模式 / 屏蔽娱乐 App | 网页无权限读取其他应用状态 |
| 白噪音 / 线上自习室 | 与核心无关，是 App 为留存硬加的；真需要的人会开音乐 App |
| 闹钟 / 在线铃声库 | 系统闹钟更可靠（能穿透静音、能后台响），做不过 |
| 天气 / 日历信息 | 信息噪音，破坏摆件的安静属性 |
| 个性签名 / 电量指示 | 无价值点缀，占版面 |

## 三、最终功能清单

### P0 · 时钟本体

- [x] 时/分/秒逐位独立翻页，四层卡片结构（静态上/下 + 下落瓣/翻起瓣）
- [x] 等宽数字 `tabular-nums`，防每秒横向抖动
- [x] 12/24 小时制切换
- [x] 秒显示开关（关闭后每分钟仅翻一次）
- [x] 日期 + 星期显示
- [x] 屏幕常亮（Wake Lock，不支持时提示）
- [x] 沉浸全屏（点击隐藏 UI）
- [x] 尺寸自适应：`min(12vw, 18dvh)` 覆盖所有屏幕
- [x] 安全区适配（刘海 / 手势条）
- [x] 翻页音效开关（WebAudio 合成，无外部文件）
- [ ] 主题 3–5 套
- [ ] 夜间自动调暗
- [ ] 防烧屏像素偏移

### P1 · 工具层

- [ ] 单击屏幕 → 底部控制面板
- [ ] 番茄钟：25/5 默认，可调，自动循环，长休周期
- [ ] 倒计时：自定义时分秒 + 常用预设
- [ ] 正计时（秒表）
- [ ] 计时中时钟降为次要信息（小字）
- [ ] 结束时：声音 + 振动 + 前台通知三兜底
- [ ] 专注记录：今日番茄数 / 今日总时长 / 近 7 日柱状
- [ ] 本地存储（localStorage），无账号无云

### P2 · 安装与分发

- [ ] PWA Manifest：`start_url` 直达时钟页、`display: standalone`
- [ ] 图标：192 / 512 / maskable 三种
- [ ] Service Worker：离线可用
- [ ] 主屏快捷方式（`shortcuts`）：直达番茄钟、倒计时
- [ ] iOS 专用 meta（`apple-touch-icon`、`apple-mobile-web-app-*`）

## 四、网页端硬限制

| 能力 | iOS Safari | Android Chrome | 处理方式 |
|---|---|---|---|
| 主屏图标 + 独立窗口 | 支持（分享→添加到主屏幕） | 支持（WebAPK） | PWA manifest |
| 屏幕常亮 | 16.4+ 支持 | 支持 | Wake Lock + 降级提示 |
| 全屏 | **不支持元素全屏** | 支持 | 靠 standalone 模式 |
| 桌面小组件 | **不支持** | 实验性 | 砍掉，改快捷方式 |
| 锁屏替代 / 屏保 | **不支持** | 不支持 | 砍掉 |
| 后台计时精度 | 节流 | 节流 | 用时间戳差值，不用累加 |
| 振动 | **不支持** | 支持 | 有则用，无则跳 |
| 通知 | 16.4+ 且需 PWA 已安装 | 支持 | 前台通知兜底 |

**关键实现原则：计时绝不用 `setInterval` 累加**，一律缓存开始时间戳，每次渲染用 `Date.now() - startTs` 重算。这样切后台、锁屏、切标签页回来都是准的。

## 五、界面结构

```
启动
 └─ 时钟态（全屏，只有数字）
     ├─ 单击 → 底部面板滑入
     │   ├─ 番茄钟
     │   ├─ 倒计时
     │   ├─ 正计时
     │   ├─ 记录
     │   └─ 设置（主题/12-24/秒/音效/亮度）
     ├─ 双击 → 翻页音效开关
     └─ 长按 → 直接进设置
```

设计原则：**默认状态下屏幕上一个按钮都没有**。所有 UI 都要能收干净。
